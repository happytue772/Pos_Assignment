# C언어 기반 편의점 POS 시스템

C언어의 구조체, 배열, 조건문, 반복문, 파일 입출력, 시간 처리 기능을 활용해 구현한  
**터미널 기반 편의점 POS 시스템**입니다.

판매·환불·입고·삭제로 변경된 상품 정보를 `products.csv`에 즉시 저장하여  
프로그램을 다시 실행해도 변경된 재고와 상품 정보가 유지되도록 구현했습니다.

---

## 기술 스택

`C11` · `GCC` · `Ubuntu 18.04` · `VS Code` · `CSV File I/O` · `time.h`

---

## 주요 기능

- 사용자 로그인 및 로그인 시간 기록
- 상품 재고 조회 및 별표(`*`) 표시
- 상품 판매 / 환불
- 상품 입고 / 검색 / 삭제
- 판매 금액 및 거스름돈 계산
- 현재 잔고 및 매출액 계산
- 담배·주류 판매 시 생년월일 기반 성인 확인
- 우유·두부 24시간 / 오뎅 1시간 유통기한 관리
- 근무시간 및 수당 계산
- 종료 시 근무·매출 정보를 `work_log.txt`에 저장
- 상품 변경 결과를 `products.csv`에 즉시 반영

## 데이터 구조

상품 하나의 정보를 `Product` 구조체로 관리했습니다.

```c
typedef struct {
    char name[100];
    int price;
    int stock;
    int adultOnly;
    char expiryAt[32];
} Product;
```

여러 상품은 구조체 배열로 관리합니다.

```c
Product products[MAX_PRODUCTS];
```

프로그램 실행 시 CSV 데이터를 구조체 배열로 불러오고,  
상품 상태가 변경되면 다시 CSV 파일에 저장합니다.

```text
products.csv
     ↓
loadProducts()
     ↓
Product 배열
     ↓
판매 / 환불 / 입고 / 삭제
     ↓
saveProducts()
     ↓
products.csv
```

## 판매 처리 흐름

판매 시 바로 재고를 변경하지 않고 다음 순서로 검증합니다.

```text
상품 검색
   ↓
재고 확인
   ↓
유통기한 확인
   ↓
성인 상품 확인
   ↓
판매 수량 확인
   ↓
결제 금액 확인
   ↓
재고·매출·잔고 변경
   ↓
CSV 저장
```

검증을 모두 통과한 거래만 실제 데이터에 반영되도록 구성했습니다.

## 문제 해결

### 1. 입력 버퍼 문제

`scanf()`를 숫자와 문자열 입력에 혼용할 경우  
Enter의 개행문자가 다음 입력에 영향을 줄 수 있었습니다.

이를 줄이기 위해 `fgets()`로 한 줄 전체를 입력받고,  
숫자가 필요한 경우 `strtol()` 또는 `strtoll()`로 변환했습니다.

**결과**
- 문자열과 숫자 입력 흐름 안정화
- 잘못된 숫자 입력 시 재입력 가능

---

### 2. 재실행 시 재고 초기화 문제

구조체 배열에서만 재고를 변경하면 프로그램 종료 후  
변경된 데이터가 사라지는 문제가 있었습니다.

판매·환불·입고·삭제 성공 후 `saveProducts()`를 호출해  
현재 상품 상태를 `products.csv`에 저장하도록 수정했습니다.

**결과**

```text
상품 변경
   ↓
CSV 저장
   ↓
프로그램 종료
   ↓
재실행
   ↓
변경된 상태 유지
```

---

### 3. 잘못된 거래 처리

다음과 같은 잘못된 입력이 들어올 수 있었습니다.

- 존재하지 않는 상품
- 현재 재고보다 많은 판매 수량
- 0 이하의 판매 / 환불 수량
- 결제 금액보다 적은 입금액
- 유통기한이 지난 상품
- 성인 조건을 만족하지 않는 상품

상태를 변경하기 전에 `if`문으로 조건을 검사하고,  
문제가 있으면 `return`으로 해당 거래를 종료하도록 구현했습니다.

이를 통해 정상적인 거래에 대해서만  
재고·매출·잔고가 변경되도록 처리했습니다.

```text
C_POS_Assignment/
├── main.c
├── products.csv
├── work_log.txt
└── .gitignore
```

- `work_log.txt` : 로그인·근무시간·수당·매출 기록

## 빌드 및 실행

Ubuntu/Linux 환경에서 프로젝트 폴더로 이동합니다.

```bash
cd C_POS_Assignment
```

컴파일:

```bash
gcc -std=c11 main.c -o pos
```

실행:

```bash
./pos
```

## 사용한 C 핵심 개념

- `struct` : 상품 정보 구조화
- 구조체 배열 : 여러 상품 관리
- `if` : 재고·결제·성인·유통기한 조건 검사
- `switch` : 메인 메뉴 / 업무 메뉴 처리
- `for` : 상품 검색 및 배열 처리
- `while` : 메뉴 반복 및 입력 재시도
- `fgets()` : 문자열 입력
- `strtol()`, `strtoll()` : 문자열을 숫자로 변환
- `fopen()`, `fprintf()`, `fclose()` : 파일 입출력
- `time()`, `localtime()`, `difftime()` : 시간 처리
