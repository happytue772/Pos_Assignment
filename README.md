# C Console POS System

C언어의 구조체, 배열, 파일 입출력, 조건문, 반복문, 시간 처리 기능을 활용해 구현한  
**터미널 기반 편의점 POS 시스템**입니다.

단순 메뉴 출력 프로그램이 아니라 로그인부터 상품 조회, 판매·환불, 재고 관리,
성인 상품 확인, 유통기한 관리, 근무시간·수당 계산까지 하나의 POS 업무 흐름으로 구현했습니다.

---

## 1. Project Overview

- **프로젝트명**: C언어 기반 편의점 POS 시스템
- **개발 형태**: 1인 프로젝트
- **개발 언어**: C
- **표준**: C11
- **개발 환경**: VMware Ubuntu 18.04 / VS Code
- **컴파일러**: GCC
- **데이터 저장**: CSV / TXT

### 개발 목표

C언어에서 학습한 구조체, 배열, 함수, 조건문, 반복문, 파일 입출력과 시간 처리를
하나의 실제 프로그램 흐름에 적용하는 것을 목표로 했습니다.

특히 판매나 환불로 변경된 재고가 프로그램 종료 후 사라지지 않도록
`products.csv`와 프로그램의 `Product` 구조체 배열을 연결하여
**상품 데이터가 지속적으로 유지되는 구조**를 구현했습니다.

## 3. Main Features

### 로그인

- 사용자 이름 / 비밀번호 입력
- 로그인 실패 시 최대 3회까지 재시도
- 로그인 성공 시간을 자동 기록

### 재고 관리

- 전체 상품 재고 조회
- 재고 수량을 숫자와 `*`로 함께 표시
- 상품 검색
- 신규 상품 입고
- 기존 상품 중복 확인 후 추가 입고
- 상품 삭제
- 변경된 상품 데이터를 CSV에 즉시 저장

예시:

```text
빵        ********  (8개)
우유      *****     (5개)
달걀      ****      (4개)
```

### 상품 판매

판매 전 다음 조건을 순서대로 검사합니다.

```text
상품 존재 여부
      ↓
재고 확인
      ↓
유통기한 확인
      ↓
성인 상품 확인
      ↓
판매 수량 확인
      ↓
결제 금액 확인
      ↓
판매 처리
```

정상적으로 판매되면:

- 상품 재고 감소
- 총 판매액 증가
- 현재 잔고 증가
- 거스름돈 계산
- `products.csv` 즉시 저장

### 상품 환불

- 상품 존재 여부 확인
- 등록된 상품 가격과 환불 가격 비교
- 환불 수량만큼 재고 증가
- 총 환불액 증가
- 현재 잔고 감소
- 변경 결과 CSV 저장

### 성인 상품 확인

담배·맥주·소주와 같은 상품은 `adultOnly` 값을 통해 관리합니다.

판매 시 생년월일을 `YYYYMMDD` 형식으로 입력받아 현재 날짜를 기준으로 만 나이를 계산하며,
설정된 조건을 충족하지 않으면 판매를 중단합니다.

### 유통기한 관리

일부 상품은 입고 시점을 기준으로 유통기한을 자동 설정합니다.

| 상품 | 유통기한 |
|---|---:|
| 우유 | 24시간 |
| 두부 | 24시간 |
| 오뎅 | 1시간 |

판매 전 현재 시간과 유통기한을 비교하여
이미 만료된 상품은 판매되지 않도록 처리했습니다.

### 매출 및 잔고 관리

기본 잔고는 과제 요구사항에 따라 **390,500원**으로 시작합니다.

판매와 환불이 발생하면 실시간으로:

- 총 판매액
- 총 환불액
- 순 매출액
- 현재 잔고

를 계산합니다.

### 근무시간 및 수당

업무 메뉴에 처음 진입한 시점을 근무 시작 시간으로 기록합니다.

```text
근무시간 = 현재시간 - 업무시작시간
수당 = 근무시간(분) × 9,800원
```

로그인 시간과 실제 업무 시작 시간을 구분하여 관리했습니다.

### 종료 로그

프로그램 종료 시 비밀번호를 다시 확인합니다.

정상적으로 종료되면 다음 정보를 출력하고 `work_log.txt`에 저장합니다.

- 로그인 시간
- 업무 시작 시간
- 종료 시간
- 총 근무시간
- 오늘 수당
- 총 판매액
- 총 환불액
- 순 매출액
- 최종 잔고

## 4. Data Structure

상품 하나의 정보를 `Product` 구조체로 관리합니다.

```c
typedef struct {
    char name[100];
    int price;
    int stock;
    int adultOnly;
    char expiryAt[32];
} Product;
```

여러 상품은 구조체 배열을 이용합니다.

```c
Product products[MAX_PRODUCTS];
```

각 상품은 다음 정보를 하나의 구조로 관리합니다.

```text
Product
 ├─ name        상품명
 ├─ price       가격
 ├─ stock       재고
 ├─ adultOnly   성인 상품 여부
 └─ expiryAt    유통기한
```

## 5. CSV Persistence

프로그램 시작 시:

```text
products.csv
      ↓
loadProducts()
      ↓
Product 배열
```

판매·환불·입고·삭제 등으로 상품 데이터가 변경되면:

```text
Product 배열 변경
      ↓
saveProducts()
      ↓
products.csv 저장
```

이 구조를 통해 프로그램을 종료했다가 다시 실행해도
이전에 변경된 상품과 재고 상태를 유지할 수 있습니다.

### products.csv 예시

```csv
name,price,stock,adult_only,expiry_at
빵,1800,8,0,-
우유,2200,5,0,2026-09-10_10:00:00
담배,4500,10,1,-
```

## 6. Input Validation

숫자와 문자열 입력이 반복되는 POS 프로그램 특성상
입력 처리를 별도의 함수로 분리했습니다.

문자열 입력은 `fgets()`를 사용하고:

```c
fgets(buf, size, stdin);
```

메뉴 번호, 가격, 수량처럼 숫자가 필요한 경우에는
`strtol()` 또는 `strtoll()`로 변환합니다.

```text
키보드 입력
   ↓
fgets()
   ↓
문자열
   ↓
strtol() / strtoll()
   ↓
정수 값
```

숫자가 아닌 값을 입력하면 다시 입력하도록 처리했습니다.

## 8. Problem Solving

### 1. 숫자 입력 후 다음 입력이 넘어가는 문제

`scanf()`를 숫자 입력과 문자열 입력에 혼용할 경우
Enter로 입력된 개행문자가 입력 버퍼에 남아 다음 입력에 영향을 줄 수 있었습니다.

입력 방식을 `fgets()` 중심으로 통일하고 숫자가 필요한 경우
`strtol()` / `strtoll()`로 변환하도록 변경했습니다.

**결과**

- 문자열·숫자 입력 흐름 안정화
- 잘못된 숫자 입력 시 재입력 가능

---

### 2. 프로그램 재실행 시 재고가 원래 값으로 돌아가는 문제

구조체 배열만 변경하면 프로그램 종료 시 메모리 데이터가 사라집니다.

따라서 판매·환불·입고·삭제가 정상적으로 완료된 이후
`saveProducts()`를 호출해 현재 상태를 CSV에 다시 저장하도록 구현했습니다.

**결과**

```text
프로그램 실행
→ 상품 변경
→ CSV 저장
→ 프로그램 종료
→ 재실행
→ 변경된 상태 유지
```

---

### 3. 잘못된 입력으로 상품 상태가 변경되는 문제

사용자가 다음과 같은 값을 입력할 가능성이 있습니다.

- 존재하지 않는 상품
- 현재 재고보다 많은 판매 수량
- 0 이하의 판매/환불 수량
- 결제금액보다 적은 입금액
- 유통기한이 지난 상품

이를 그대로 처리하면 음수 재고나 잘못된 매출 값이 발생할 수 있습니다.

상태를 변경하기 전에 `if`문으로 조건을 검사하고,
조건을 만족하지 않으면 `return`을 통해 해당 작업을 중단하도록 구성했습니다.

**결과**

정상적인 거래에 대해서만 재고·매출·잔고가 변경되도록 했습니다.

## 11. Key C Concepts

이 프로젝트에서 사용한 주요 C 개념입니다.

- `struct` : 상품 데이터 구조화
- 구조체 배열 : 여러 상품 관리

- `while` : 메뉴 반복 / 입력 재시도
- `fgets()` : 문자열 입력
- `strtol()`, `strtoll()` : 문자열 → 숫자 변환
- `fopen()`, `fprintf()`, `fclose()` : 파일 저장
- `time()`, `localtime()`, `difftime()` : 시간 처리
